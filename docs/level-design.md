# 关卡设计

原稿（含俯视草图）：https://claude.ai/artifact/FUQMG5Wtw313mFWLg8Hihm#d6c4414f-c743
当前重点：**先做好第 1 关**（第一周原型目标），第 3 关暂缓。草图是示意，尺寸等原型调好手感数值后再定。

## 关卡设计规则

先决定玩家从哪里能看到什么，再搭墙。每关按这个顺序做：核心时刻 → 摄像头覆盖图 → 灰盒 → 试玩 → 氛围。

1. **核心时刻一句话**：一个新机制 + 一个协作谜题 + 一次惊吓（可以没有）
2. **地标优先**：每个摄像头里至少有一个地标也出现在另一个画面里（红色地面条纹、门上的大号编号、闪烁的灯）。不加说明文字，让空间自己说话
3. **门口是交接点**：机器人穿过一扇门，正好进入下一个摄像头的视野
4. **新视角先给清楚的地标**：第一次出现旋转或镜像视角的画面，必须有一个特别显眼的参照物
5. **死路有回报**：一份文件、一段录音或一个预兆
6. **紧张和放松交替**：窄而暗的盲区之后，接一个监控齐全、光线稳定的房间
7. **教学不用句子**：按键提示只以操作台上的按键图标出现一次，其余靠关卡布局引导

## 场景设计：围绕两种视角的差异

每个房间都要回答一个问题：**这里监控负责什么，机载负责什么？** 机载只看得到一小块但看得清，监控看得到全局但看不清。下面是从这个差异推出的场景模式。

| 模式 | 怎么做 | 先用在 |
| --- | --- | --- |
| 找与读 | 监控找到东西在哪，机载凑近读出内容 | 第 1 关纸张 |
| 只有从上面看得出 | 地面标线、污染区的形状、安全通道；机器人太矮看不出全貌，必须看着监控驾驶 | 第 2 关热室、第 4 关实验室 |
| 只有凑近看得出 | 一排相同的阀门只有铭牌不同、地上一根细线、墙上的裂缝；监控里全都一样 | 第 4 关阀门 |
| 遮挡之下 | 管道下、货架底、通风管里监控看不到，只能靠机载 | 第 5 关档案库货架间 |
| 远程驾驶 | 又大又空、没有特征的大厅，或需要精确绕行的障碍；只靠机载会迷失方向，必须透过监控把机器人「开」过去 | 第 3 关泵房（暂缓）、第 6 关 |
| 视角错位 | 监控镜像或旋转，要在脑子里转换方向 | 第 2 关 |
| 画面对不上 | 监控是循环的假画面，只有机载看到的是真的 | 第 5 关 |

节奏上让模式交替：一段非得看监控「开」的区域，接一段非得凑近看的区域，玩家会自然地频繁切换。

## 视角约束：不硬锁，让只靠机载变得很慢

不禁止玩家只用机载找路，而是让它变得很慢、容易迷路、心里没底。分三层使用：

| 层 | 手段 | 用法 |
| --- | --- | --- |
| 始终开启 | 头灯 3～4 米、视点低、视野 60°、转向慢（约 45°/秒）、画面无方位信息 | 第一周原型就定下，所有关卡通用 |
| 每关主力 | 重复 + 比摄像头高的遮挡；一个「只有监控看得出的关系」；一件「只有机载做得到的事」 | 每关至少各一个 |
| 少量使用 | 时间压力（第 3 关起，只在威胁区域）、地面图案（第 2、4 关各一次）、硬锁（最多一次剧情节点） | 按关卡节奏安排 |

**每关检查清单**

- [ ] 遮挡物比机载摄像头高（约 1.2 米以上），而且长得一样
- [ ] 出口或目标在头灯范围之外，或者和其他门长得一样
- [ ] 有一个只有监控看得出的关系（哪一个、在哪、哪条路）
- [ ] 有一件只有机载做得到的事（读字、看颜色、看遮挡物下面）
- [ ] 每个摄像头里至少有一个跨画面的地标
- [ ] 前期关卡没有又大又空的房间
- [ ] 试玩：只靠机载通关的时间 ≥ 用监控的 3 倍；用了监控还迷路，就是地标不够

第 1 关的货箱迷宫按这个来做：货箱一模一样、比摄像头高，迷宫里有两三条死路，出口在对角，开局正对一面箱墙。

## 第 1 关：控制室走廊

**核心时刻**：完整教一遍两种视角的关系——机载看不到全局 → 监控看得到全局、可以透过它开车 → 两者合作 → 各自都有对方看不到的东西。无威胁，只有一个预兆。

### 布局（俯视，从左到右）

- **装载区**（左侧大房间）：漆黑，五堆一模一样的货箱围成小迷宫，比机器人摄像头高，有两三条死路。机器人开局在左下角，正对一面箱墙。**CAM-1** 在机器人身后的墙角高处，朝向与机器人一致（画面上方 = 机器人前方），覆盖整个装载区。出口在对角（右上）
- **走廊**（短）：从装载区出口向右，连接警卫室和 17 号门
- **警卫室**（走廊下方，门开着）：桌子、翻倒的椅子，地上散落十几张纸；写着密码的那张单独落在椅子旁。**CAM-2** 在房间对角高处俯视整个房间
- **17 号门**（走廊尽头）：锁着，旁边是密码面板
- **控制室**（右侧）：控制台、下行电梯。**CAM-3** 在右上角俯视。控制台底下有一道拖痕，只有机载经过时看得到

### 流程

1. **机载的局限**：起点在漆黑的装载区，机器人正对着倒塌的货箱，头灯只照得到箱子，找不到出口。操作台上的 Shift 图标亮一次
2. **透过监控开车**：CAM-1 在高处墙角，红外画面，整个装载区一览无余。朝向和机器人一致，透过它把机器人开出货箱迷宫。第一次体验分离感
3. **监控找、机载读**：17 号门锁着。警卫室地上散落着十几张纸，机载画面里张张都一样；CAM-2 俯视能看出有一张单独落在翻倒的椅子旁，但读不出字。透过监控开过去，切回机载读出密码
4. **开门**：回到 17 号门，在密码面板输入密码（面板接管数字键，这时不切监控）
5. **机载才看得到的预兆**：控制室的 CAM-3 一切正常；机器人经过控制台时，机载画面里有一道新鲜的拖痕通向控制台底下，监控从上面看不到。进入电梯，关卡结束

预计 3 分钟左右。第 4 关的预兆是监控里多出来的一帧（帧间者登场前），这关是机载才看得到的细节，两种预兆互相对照。

### 待细化

1. 三路监控各自的构图（高度、拍到什么、机器人在画面里多大）
2. 开场 30 秒：不用文字，怎么教会移动、头灯、Shift
3. 货箱迷宫的具体布局与难度
4. 纸张谜题细节：密码内容、从上方区分那张纸的特征、机载凑近看到的细节
5. 每个节拍的声音
6. 拖痕预兆的具体表现，后面要不要回收
7. 尺寸（等原型手感数值）
8. 走廊和 17 号门由哪路监控覆盖：出装载区进走廊时没有摄像头交接（见「门口是交接点」）

## 第 3 关：断电区（暂缓）

**核心时刻**：断电后摸黑穿过盲区，在盲区里第一次听到不属于机器人的声音；恢复供电后，听声者在泵房登场。

1. **入口**：只有 CAM-A 能用（备用电源，低帧率）。从监控里记住走廊长度和转角的应急灯
2. **进入盲区**：过了应急灯就没有任何监控，只能靠头灯、滴水声和刚才记下的距离摸过去
3. **声音**：盲区中段，身后传来刮擦声。转身去看，什么都没有
4. **配电室**：拉下闸刀，CAM-B、CAM-C 上线。切到 CAM-B 回看走廊，某一帧里有个东西站在那（预兆）；发电机的轰鸣声也在这时响起
5. **泵房**：听声者登场。金属格栅一走就响，混凝土地面安静。切到 CAM-C 看它巡逻，等它走远再穿过格栅，到达货运电梯

预计 3～4 分钟。这关里「协作」的形式是：看 CAM-C 的同时操控机器人，靠监控里的朝向箭头判断方向。
